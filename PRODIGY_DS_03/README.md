**Project 03: Predictive Modeling with Decision Tree Classification**

**Project Overview**
This project focuses on building a Decision Tree Classifier to predict customer behavior. Using a marketing dataset, the objective was to develop a model that can categorize whether a customer will subscribe to a specific product or service based on their demographic and behavioral profiles.

**Technical Objectives**
Data Preprocessing: Handled categorical variables through label encoding and dummy variable creation.

Exploratory Data Analysis (EDA): Identified key drivers of customer conversion (e.g., age, balance, and previous contact duration).

Model Implementation: Utilized Scikit-Learn to build and train a Decision Tree Classifier.

Hyperparameter Tuning: Optimized the tree depth to prevent overfitting and ensure better generalization on unseen data.

**Tools & Libraries Used**

Python: Core programming language.

Pandas: For data manipulation and structural analysis.

Scikit-Learn: For model building, training, and evaluation.

Matplotlib/Seaborn: For visualizing the decision tree structure and feature importance.

****Key Insights**

The model effectively segmented customers based on contact duration and housing status.

Visualizing the decision tree provided a clear, interpretable "logic map" that can be used by business stakeholders to understand the decision-making process.

How to Run:

Clone the repository.

Install dependencies: pip install pandas scikit-learn matplotlib seaborn.

Run the Jupyter Notebook or Python script to view the model evaluation metrics.
