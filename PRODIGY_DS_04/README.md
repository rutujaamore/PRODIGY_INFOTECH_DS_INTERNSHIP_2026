****Project 04: Sentiment Analysis and Natural Language Processing (NLP)**

**Project Overview****

This project involves the development of a sentiment analysis framework to categorize and visualize public opinion within social media datasets. The objective was to extract meaningful emotional trends from unstructured text data, providing insights into consumer sentiment and regional discourse patterns.

**Technical Objectives**
Data Text Sanitization: Built a custom NLP pipeline to clean raw text data by removing noise such as URLs, stop words, and special characters using Regex and NLTK.

Sentiment Classification: Categorized text into Positive, Negative, and Neutral labels to analyze the overall emotional tone of the dataset.

Exploratory Data Analysis (EDA): Performed frequency analysis to identify dominant themes and keywords within specific sentiment categories.

Visual Intelligence: Created high-fidelity Word Clouds and distribution charts to represent the most impactful terms and the volume of sentiment across different entities.

**Tools & Libraries Used**
Python: Core language for text processing.

NLTK (Natural Language Toolkit): For tokenization and text preprocessing.

Pandas: For data structuring and categorical manipulation.

Matplotlib & Seaborn: For plotting sentiment distributions.

WordCloud: For generating visual keyword clusters.

**Key Insights**
The analysis revealed a strong correlation between specific entities and positive brand sentiment, while also identifying clusters of negative feedback that require strategic attention.

By utilizing Word Clouds, the most frequent "pain points" and "delight factors" were instantly identifiable for stakeholders.
